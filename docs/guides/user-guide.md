# 학생 사용 가이드

> **대상**: 42 학생 사용자.
> **플랫폼**: 모바일 앱 (iOS/Android) + 웹 (브라우저).
> **버전**: v0.6.0 기준.

이 가이드는 도서 검색부터 대출·예약·추천까지 학생이 자주 쓰는 흐름을 설명합니다. 화면 캡처는 [별도 PR로 추가 예정] — 우선 텍스트로 절차만 정리합니다.

## 0. 시작하기

### 앱 설치 / 접속

- **iOS**: TestFlight 링크 (배포 시점 별도 공지)
- **Android**: APK 직접 설치 또는 Play Store (배포 결정 후)
- **웹**: `https://lib.your-domain.kr` (호스팅 도메인 안내 별도)

### 첫 로그인 (42 OAuth)

1. 첫 화면에서 **`로그인`** 탭.
2. **`42 계정으로 로그인`** 선택 → 42 인트라 페이지로 이동.
3. 42 인트라 자격증명 입력 → 권한 승인.
4. 자동으로 앱으로 돌아옴 → 대시보드 표시.

> 한 번 로그인하면 토큰이 안전 저장소에 보관되어, 앱을 다시 켜도 자동 로그인됩니다. 7일 간 유효합니다.

## 1. 도서 찾기

### 1.1 도서 목록 보기

- 로그인 직후 **`/`** (홈) — 전체 도서 목록 표시.
- 화면 너비에 따라:
  - 큰 화면: 4열 그리드
  - 중간: 2열 그리드
  - 좁은 화면 (모바일): 1열 리스트

### 1.2 검색

- 상단 검색바에 **제목**을 입력 (디바운스 0.5초).
- ✕ 버튼으로 검색어 초기화.
- 카테고리 필터는 향후 추가 예정.

### 1.3 도서 상세

- 카드 탭 → `/books/:id` 상세 화면.
- 정보:
  - 표지 / 제목 / 저자 / ISBN / 출판년도 / 카테고리
  - 보유 수량 + 대출 가능 수량
  - 대출 요청 / 예약 버튼

## 2. 도서 대출

### 2.1 대출 요청 (재고 있을 때)

1. 도서 상세 화면에서 **`대출 요청`** 버튼 (파란색, 책 아이콘).
2. 확인 다이얼로그 → **`확인`**.
3. 녹색 스낵바: **"대출 요청이 접수되었습니다"**.
4. `/my-loans`에서 상태 확인 가능 (초기 상태: `대기 중 (pending)`).

### 2.2 예약 (재고 없을 때)

1. 도서가 모두 대출 중이면 버튼이 **`예약 대기열 추가`** (주황색, 큐 아이콘)로 바뀜.
2. 확인 다이얼로그 → **`확인`**.
3. 주황색 스낵바: **"도서가 품절되어 예약 대기열에 추가되었습니다 (대기 순위: N)"**.
4. `/my-loans`에서 본인 순위 확인 가능.

> **예약 알림 흐름**: 누군가 책을 반납하면 큐의 첫 번째 학생에게 자동 알림 (24시간 안에 대출 신청해야 함). 시간 안에 신청하지 않으면 자동 만료되고 다음 순위로 넘어갑니다.

## 3. 내 대출 / 예약 관리

### `/my-loans`

탭별로:
- **대출 요청**: 신청 상태 (`대기 중` / `승인` / `반려` / `취소`).
- **예약**: 대기 중인 예약 (`waiting` / `notified` 상태) + 본인 순위.

### 3.1 대출 요청 취소

- 상태가 `대기 중 (pending)`인 행만 취소 가능.
- 행의 **`취소`** 버튼 → 확인 → 즉시 취소.

### 3.2 예약 취소

- 상태가 `waiting` 또는 `notified`인 행만 취소 가능.
- 행의 **`취소`** 버튼 → 확인 → 큐가 자동으로 재정렬됨 (뒤 학생들의 순위가 한 칸씩 앞당겨짐).

## 4. 도서 추천

도서관에 없는 책을 도입해 달라고 학생이 제안할 수 있습니다.

### 4.1 활성 수집 기간 확인

- `/suggestions/mine` 진입 시 상단에 현재 활성 수집 기간 표시 (예: `2024 Q1 (~3월 31일)`).
- 기간이 없으면 추천 제출 불가.

### 4.2 새 추천 제출

1. **`새 추천`** 버튼 → `/suggestions/new`.
2. 폼 입력:
   - **제목** (필수)
   - **저자** (필수)
   - **추천 사유** (선택, 자유 텍스트)
3. **`제출`** → 활성 기간에 귀속됨.

> 같은 책 (제목+저자가 일치)을 같은 기간에 두 번 제출하면 거절됩니다 (중복 방지).

### 4.3 내 추천 목록

- `/suggestions/mine` — 본인이 제출한 추천.
- 상태:
  - **`제출됨 (submitted)`** — 검토 대기
  - **`검토중 (under_review)`** — 관리자가 평가 중
  - **`승인 (approved)`** — 도서관 도입 결정
  - **`반려 (rejected)`** — 도입 거절 (관리자 메모 표시될 수 있음)

## 5. 트러블슈팅

| 증상 | 원인 / 해결 |
|--|--|
| 로그인 후 화면이 비어있음 | 토큰 만료. 다시 로그인. |
| 대출 요청 버튼이 비활성화 | 같은 책에 이미 `대기 중` 신청이 있음. `/my-loans`에서 확인. |
| "활성 수집 기간이 없습니다" | 추천을 받지 않는 기간. 관리자가 새 기간을 만들 때까지 대기. |
| 검색 결과가 0건 | 디바운스 0.5초 — 입력 후 잠시 대기. 그래도 0건이면 도서관에 없는 책 → 추천 제출 고려. |
| 예약 알림이 오지 않음 | 푸시 알림은 v0.6.0 기준 미구현. `/my-loans`에서 직접 확인 필요 (향후 개선 예정). |

## 6. 개인정보 / 보안

- 42 OAuth 이외의 비밀번호는 저장하지 않습니다.
- 토큰은 `flutter_secure_storage` (iOS Keychain / Android Keystore)에 보관됩니다.
- 학생 정보 (이름, 이메일, 42 ID)는 매 로그인마다 42 인트라에서 갱신됩니다.
